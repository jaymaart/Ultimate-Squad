# Ultimate Squad Desktop

Desktop app for Ultimate Squad, the free NFL card-collecting and team-building game. A native window around [ultimatesquad.xyz](https://ultimatesquad.xyz) for Windows, macOS and Linux.

The app is the same game as the website, with the same account and the same progress: sign in with Discord, open packs, build your squad, play seasons and live head to head matches, and trade on the auction house. It needs an internet connection.

## First launch

The app is not code-signed yet, so your system will warn you the first time.

- **Windows:** if SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**. The installer sets up for your user only and does not ask for administrator access.
- **macOS:** open the dmg and drag the app to Applications. If macOS says it cannot verify the app, right-click it, choose **Open**, then **Open** again.
- **Linux:** make the file executable (`chmod +x Ultimate-Squad-linux.AppImage`) and run it.

## Updates

The game itself is always the newest version, because the app opens the live site. When the app
itself has a new version, an **Update** button appears in the title bar. Click it to install and
restart. Click the version number in the title bar to check by hand. If an update ever fails, the
latest installers are always on the [Releases](https://github.com/jaymaart/Ultimate-Squad/releases) page.
